# Super Samus World: Fallen Mushroom Kingdom — v0.6.0 Alpha

The Mushroom Kingdom has fallen silent. Something dangerous now walks its familiar paths—and Samus is stepping into the ruins.

Explore a darker take on a familiar world, with rebuilt character animations, a new soundtrack, distinct level palettes, and enemies that do more than wait to be shot. Expect armored opponents, relentless pursuers, tactical firefights, and explosive combat.

[Download v0.6.0 — The Gamba Build](https://github.com/starssthedegen/Super-Samus-World/releases/tag/v0.6.0)

Download the **Windows-x64 ZIP** to play. The separate **source ZIP** contains the matching engine/frontend source and build instructions.

Already implemented:

- Widescreen gameplay, detailed player/character rendering, and numerous terrain, platform, HUD, and sprite-edge fixes.
- Gamba secret guardians, Harpies, redesigned aquatic enemies and shelled crawlers, plus Rexes and Koopas.
- Beam, charge beam, missiles, and Morph Ball combat with revised damage balance, PC sound effects, and shared enemy defeat effects.
- Standing swimming, underwater weapons, normal pipe entry/exit, and jumping out of water onto land.
- SNES-style controller setup, button-layout help, custom music, and separate music/effects volume controls.
- Normal locked level progression. Release downloads include no saves, test unlocks, debug captures, ROMs, or extracted caches.

This is an actively developed alpha. Full campaign testing is ongoing. Gamba can occasionally get stuck or handle beam pressure poorly; an intermittent Iggy boss report remains unreproduced. See the release notes for details.

Windows PC. Free to play. First-time setup requires player-supplied compatible **Super Mario World (USA)** and **Super Metroid (Japan, USA)** ROMs. Keep the entire extracted game folder together. Back up existing progress before updating.
